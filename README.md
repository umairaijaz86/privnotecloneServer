# Secure Notes (Express + TypeScript)

A simple project inspired by PrivNote to share secure, self-destructing notes.  
This repository is built step by step, keeping the README updated after each task.

---

## 📌 Current Progress
- ✅ Task 1: Project bootstrapped with **Express + TypeScript**.
- ✅ `/health` endpoint returns `{ status: "ok", uptime: number }`.
- ✅ `.env` support added for configuration (currently `PORT`).
- ⬜ Task 2: MongoDB connection & Note schema (next).
